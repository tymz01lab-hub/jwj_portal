Windows · Mac 공통 전시 실행

‘스케이트보드 전시 시작.html’ 파일 하나만 다른 컴퓨터에 복사하세요.
두 번 클릭하면 기본 브라우저에서 배포된 최신 전시 사이트가 열립니다.
Chrome을 기본 브라우저로 설정해 두세요. 인터넷 연결이 필요합니다.
처음 열 때는 Chrome에서 카메라 사용을 허용하세요.
이 HTML 파일은 옆에 다른 폴더나 이미지 파일이 없어도 작동합니다.

종료할 때는 전시 창을 직접 닫으세요.
Windows: Alt + F4 / Mac: Command + W
공통 HTML 파일은 다른 브라우저 창을 강제로 닫거나 자동으로 전체 화면으로 바꿀 수 없습니다.

Windows 전용 전시 시작·종료 EXE는 ‘웹 실행’ 폴더에도 그대로 있습니다.
