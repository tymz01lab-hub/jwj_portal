다른 PC에서 전시하기 — Windows용 EXE

가벼운 방법: ‘웹 실행’ 폴더의 ‘전시 시작.exe’만 복사하세요.
이 파일 하나로 최신 웹사이트가 Chrome에서 열립니다. Chrome과 인터넷이 필요합니다.
‘전시 종료.exe’는 선택 사항이며, 없으면 전시 창에서 Alt + F4로 종료할 수 있습니다.

아래는 콘텐츠를 함께 담은 큰 ZIP 패키지를 사용하는 방법입니다.

1. ‘전시 실행 패키지.zip’을 다른 PC에 복사합니다.
2. 압축파일을 마우스 오른쪽 버튼으로 눌러 ‘모두 압축 풀기’를 선택합니다.
   바탕 화면이나 문서처럼 파일을 쓸 수 있는 폴더에 풀어 주세요.
3. 압축을 푼 폴더에서 ‘전시 시작.exe’를 두 번 클릭합니다.
   전시 서버와 전용 Chrome 전체 화면 창이 함께 열립니다.
4. 처음 실행할 때 Chrome의 카메라 권한 안내에서 ‘허용’을 선택합니다.
5. 종료할 때는 Alt + Tab으로 폴더로 돌아와 ‘전시 종료.exe’를 두 번 클릭합니다.
   전시 창과 전시 서버가 함께 종료됩니다. 평소 사용하던 Chrome 창은 유지됩니다.

실행 파일 두 개와 ‘콘텐츠’ 폴더는 항상 함께 두세요.
EXE 파일만 따로 복사하거나 압축파일 안에서 바로 실행하면 콘텐츠를 찾지 못합니다.
전시 PC에는 Chrome과 인터넷 연결이 필요합니다.
Node.js 설치, 개발 도구 설치, 관리자 권한은 필요하지 않습니다.
Windows 10/11의 기본 .NET Framework를 사용합니다.
Mac에서는 이 EXE를 실행할 수 없습니다.

시작을 여러 번 눌러도 같은 전시를 중복 실행하지 않습니다.
8199번 주소를 다른 프로그램이 사용하면 안내가 나오므로 기존 전시를 먼저 종료하세요.
실행 중 .runtime-exe 폴더가 자동으로 만들어집니다.
이 폴더는 전용 Chrome 설정과 실행 상태만 담으며 다른 PC로 옮길 필요가 없습니다.
사진·영상 저장이나 서버 전송 기능은 없습니다.

기존 CMD 파일도 유지했습니다. CMD 방식은 Node.js가 설치된 개발 PC용입니다.

오류가 나거나 새 체험을 시작하려면 전시 창에서 R 키를 누르세요.
상단 ‘처음부터 (R)’ 버튼으로도 보드샵 첫 화면을 다시 불러올 수 있습니다.
