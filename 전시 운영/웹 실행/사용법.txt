가벼운 전시 실행 파일 — 웹사이트를 바로 엽니다.

‘스케이트보드 전시 시작.exe’ 하나만 다른 Windows PC로 복사해 두 번 클릭하세요.
전용 Chrome 전체 화면으로 최신 배포 콘텐츠가 열립니다.
Chrome과 인터넷 연결이 필요합니다. Node.js와 콘텐츠 폴더는 필요 없습니다.
첫 카메라 권한 안내에서는 ‘허용’을 눌러 주세요.
R 키를 누르면 보드샵 첫 화면을 새로 불러옵니다.

종료 파일도 원하면 ‘전시 종료.exe’를 함께 복사하세요.
Alt + Tab으로 돌아와 종료 파일을 누르면 전시 전용 Chrome만 닫습니다.
종료 파일 없이도 전시 창에서 Alt + F4를 눌러 닫을 수 있습니다.
웹 실행 폴더 안의 EXE 두 개는 로컬 실행용 EXE와 구분해 주세요.

웹 주소: https://tymz01lab-hub.github.io/skateboardword/
실행 상태와 Chrome 설정은 이 PC의 LocalAppData 안에 자동으로 만들어집니다.
사진이나 영상은 저장하거나 업로드하지 않습니다.
