운영 파일·개발 원본: https://github.com/tymz01lab-hub/jwj_portal
웹 배포: 기존 skateboardword 저장소의 main 변경 시 GitHub Pages가 갱신됩니다.

개발 프로젝트 전체를 받을 때는 연결된 콘텐츠 저장소도 함께 받으세요.
git clone --recurse-submodules https://github.com/tymz01lab-hub/jwj_portal.git
운영 파일이 있는 codex/jamo-park-v2 브랜치를 선택합니다.

다른 전시 PC에는 전시 실행 패키지.zip을 복사해 압축을 풀면 됩니다.
용량을 줄이려면 웹 실행/스케이트보드 전시 시작.exe 하나만 복사하세요. 배포된 웹사이트를 직접 엽니다.
개발 도구 없이 전시 시작.exe와 전시 종료.exe로 운영할 수 있습니다.
소스에서 다시 만들 때는 전시 운영/tools/build-exe.ps1을 실행합니다.
작은 웹 실행용 EXE는 전시 운영/tools/build-web-exe.ps1로 만듭니다.
테스트: node "전시 운영/tests/check-lobby.cjs"
