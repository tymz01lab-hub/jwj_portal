전시 운영 안내

1. ‘전시 시작.exe’를 두 번 클릭하세요.
   스케이트보드 통합 화면이 전용 Chrome 창에서 전체 화면으로 열립니다.
   이미 실행 중이면 창을 추가로 열지 않습니다.

2. 종료할 때는 Alt + Tab을 눌러 이 폴더로 돌아온 뒤,
   ‘전시 종료.exe’를 두 번 클릭하세요.
   전시 Chrome 창과 전시용 실행 도구가 함께 종료됩니다.
   평소 사용하던 Chrome 창은 유지됩니다.

첫 화면에서 카메라 사용을 요청합니다.
Chrome의 카메라 권한 안내에서 ‘허용’을 선택하세요.
배경을 지운 내 모습과 벽에 걸린 보드 세 개가 보입니다.
보드에 손을 가까이 대고 잠깐 기다리면 선택됩니다.
선택한 보드를 세로로 든 모습과 5초 안내가 나오고, 타는 법 배우기로 이동합니다.
다른 보드를 고르면 5초를 다시 셉니다.
사람이나 손이 보이지 않으면 자동 이동을 기다립니다.
권한을 자동으로 허용하거나 영상을 저장하는 기능은 추가하지 않았습니다.
현재 콘텐츠의 몸 동작 인식 도구를 불러올 때는 인터넷 연결이 필요합니다.

체험 순서
1. 보드샵에서 데크를 고릅니다.
2. 사람 안내 화면을 보며 두 발 점프와 두 발 벌리고 서기를 배웁니다.
   두 동작을 확인하면 자동으로 파크로 이동합니다.
3. 파크에서 보드를 탑니다.
4. 완주하면 ‘내 보드와 함께’ 화면으로 이동합니다.
   현재는 선택한 데크와 내 모습을 보여 주는 단계만 준비했습니다.
   손으로 잡기, 발 아래 붙이기, 촬영 세부 동작은 다음 수정에서 진행합니다.

몸 동작으로 타기
양쪽 무릎과 발목이 카메라에 보이게 서 주세요.
처음에는 양발을 바닥에 놓고 잠깐 멈춰 바닥 높이를 잡습니다.
두 발을 어깨너비 정도로 벌리고 서 있으면 앞으로 갑니다.
두 발을 함께 바닥에서 떼면 알리가 나옵니다.
가볍게 제자리에서 뛰어도 반응하도록 조정했습니다.
체험 진행 속도를 낮춰 알리 타이밍에 여유를 두었습니다.
무릎만 굽혔다 펴거나 한 발만 드는 동작은 알리로 처리하지 않습니다.

알리 동작
알리를 해도 파크 화면에서 계속 탑니다. 확대나 회전 단계는 없습니다.
짧은 점프가 한 번의 동작 분석에만 잡혀도 양발과 몸이 함께 올라가면 인식합니다.
발끝이 가려져도 양쪽 발목이 보이면 판단합니다.
작은 점프에 반응하도록 조정했으며, 한 발만 들기나 제자리에서 무릎만 굽히기는 알리로 처리하지 않습니다.
사진 촬영·저장·서버 전송·폴라로이드 표시 기능은 없습니다.
다른 PC로 옮길 때는 ‘다른 PC에서 실행.txt’를 참고하세요.

연결된 콘텐츠: 프로젝트 폴더 안의 skateboardword/index.html
전시 주소: http://127.0.0.1:8199
EXE 실행에 필요한 프로그램: Chrome (Node.js 설치 불필요)

개발 PC에서는 ‘전시 운영’ 폴더를 현재 프로젝트 안에 두세요.
다른 PC에는 ‘전시 실행 패키지.zip’을 복사해 풀어 주세요.
tools는 개발용 원본입니다. EXE 실행 시 .runtime-exe에 전용 Chrome 설정과 실행 상태가 만들어집니다.
실행 오류가 발생하면 안내 창을 확인하세요.

처음부터 다시 시작하기
전시 Chrome 창에서 키보드 R 키를 누르거나 상단 ‘처음부터 (R)’ 버튼을 누르세요.
보드샵 첫 화면을 새로 불러오며 선택한 보드와 진행 상태가 초기화됩니다.
알리로 점프하는 중에도 R 키를 사용할 수 있습니다.
